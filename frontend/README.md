# ⚡ Flash Sale Engine
Real-time flash sale platform.

## Live Demo
- Frontend: https://flash-sale-engine-bice.vercel.app
- Backend: https://flash-sale-engine-backend.onrender.com

## Features
- Live countdown timer
- Real-time stock updates via WebSockets
- Queue system
- Load tested: 6078 requests, 100 concurrent users, 0 failures

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: FastAPI, Python
- Real-time: WebSockets
- Deployment: Vercel + Render
